# D868UV-Enhanced

Unofficial K4RJM firmware and Windows CPS for the AnyTone AT-D868UV.

**[Download 2.41 for Windows — CPS installer and radio firmware (ZIP)](https://github.com/K4RJM/D868UV-Enhanced/releases/download/v2.41/D868UV-Enhanced-2.41.zip)**

1. Right-click `D868UV-Enhanced-2.41.zip` in Windows and choose **Extract All**.
2. To install the programming software, run `Setup-2.41.exe`. The CPS requires the stock D868UVE Windows runtime.
3. To find the radio firmware, open the extracted **Firmware** folder beside the installer. Keep `D868UV_2.41_dev3.SPI`, `D868UV_2.41_dev3.CDI`, and `D868UV_2.41_dev3.CDD` together. Installing the CPS is separate from flashing the radio.

Boot and display-color persistence were confirmed on one AT-D868UV with hardware version 1.10. [Read the 2.41 release notes](https://github.com/K4RJM/D868UV-Enhanced/releases/tag/v2.41).
